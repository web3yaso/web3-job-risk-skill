## 二、岗位风险等级

**高风险**（监管责任传导风险最高）：
BD、市场营销、KOL合作、社区运营、销售

**中风险**：
产品经理、运营、法务合规

**相对低风险**：
工程师/开发、设计、数据分析、行政HR

## 三、Token风险对照表

### 条款判断标准

| 条款 | 高风险信号 🔴 | 正常范围 🟢 |
|------|------------|-----------|
| Cliff期 | 少于6个月 | 12个月（标准） |
| Vesting总期 | 少于2年 | 4年线性（标准） |
| Token计价方式 | 以token数量计价，无保底 | 以USD计价+价格保护 |
| Token流动性 | 未上所，"计划上所" | 已在主流CEX上市 |
| 团队持仓比例 | >40%（严重中心化） | 15-20%（正常） |
| 员工期权池 | <5%（员工激励不足） | 10-15%（正常） |
| Vesting合同 | 口头承诺，无书面文件 | 独立法律文件 |

### 明显异常信号解读

- **Cliff少于6个月** → 项目方急于套现，对员工极不友好
- **团队持仓>40%** → 上所后随时可能大量抛售，token价值归零风险高
- **只有口头承诺** → 法律保护为零，离职后token极可能拿不到
- **Offer以token数量而非USD计价** → 入职时承诺的"价值"可能入职后缩水90%

## 四、Anon团队替代验证方法

当团队无法doxx时，通过以下方式评估可信度：

1. **链上历史**：过往部署合约是否按时兑现？有无链上恶意行为记录？
2. **社区时间**：核心成员X/Discord发言历史是否连贯一致（几年 vs 几个月）？
3. **审计记录**：是否有知名审计机构报告（Certik、Trail of Bits、OpenZeppelin等）？
4. **机构背书**：是否有doxxed的机构投资人公开背书？
5. **跨平台一致性**：同一人在不同平台的身份叙述是否一致？

## 六、Agency内容合规规则（各司法管辖区）

Agency的SMM/内容岗位面临特殊风险：你制作的内容是否构成"推介token"？

### 各地区规定

**美国（SEC）**：
- 若内容被认定为"solicitation"（向公众推介证券），且未披露受薪关系，可能违反证券法
- 2023年后SEC多次起诉未披露关系的KOL，agency员工同样适用

**香港（SFC）**：
- 2024年新规：社媒推广虚拟资产须明确披露商业关系
- 以个人账号发布但未披露受薪 = 潜在违规

**欧盟（MiCA）**：
- 营销传播须符合信息披露要求
- 发布方（即你）对内容合规负责，不能以"客户让我发的"为由免责

**新加坡（MAS）**：
- 2022年起禁止在公共场所推广数字支付代币服务，包括社媒
- Agency员工替客户在新加坡面向用户发内容需格外谨慎

### 自我保护核查

入职前必须确认的问题（可直接向HR提问）：
- [ ] Agency是否要求所有对外内容披露"paid partnership"或"commercial content"？
- [ ] 合同中是否有条款明确"内容合规责任由客户承担，Agency及员工免责"？
- [ ] Agency是否有内容发布前的合规审核流程？
- [ ] 你是否会被要求以**个人账号**发布客户内容？（个人账号风险远高于公司账号）
- [ ] 如果客户项目后来被认定为scam或证券违规，Agency是否有法律保护条款覆盖员工？

## 七、入职前追问清单（完整版）

**关于公司合规：**
- 公司在哪些司法管辖区持有运营牌照？牌照编号是什么？
- 我的工作合同由哪个法律实体签署？（注意：离岸壳公司签署的合同法律保护弱）
- 公司是否有专职法律合规团队？

**关于薪资安全：**
- 公司目前的现金runway是多少个月？
- 最近一轮融资的close时间和金额？
- 法币薪资是否通过独立的发薪账户发放（而非从运营账户直接转）？
- 如果公司融资失败，员工薪资有何保障机制？

**关于Token条款：**
- Token的vesting条款是否有独立的法律合同文件？（要求看原件）
- Cliff期和vesting总期分别是多少？
- 提前离职时，已vest和未vest的token分别如何处理？
- Token以USD计价还是以数量计价？有无价格下行保护？
- 公司是否会在你锁仓期内大量出售团队持有的token？

**关于岗位职责边界（高风险岗位必问）：**
- 我是否会被要求以个人账号发布内容？
- 内容发布前是否有合规审核流程？
- 如果客户项目出现法律问题，公司如何保护员工？
